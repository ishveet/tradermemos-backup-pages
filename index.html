TraderMemos Backup

TraderMemos Backup is a personal-use backup integration used by its owner to store encrypted TraderMemos backup repositories in Google Drive.

The integration uses rclone to connect to Google Drive and requests the drive.file permission, which limits access to Google Drive files created or used with this application.

Backup data is encrypted with restic before it is stored in Google Drive. This application is not offered as a public service and does not provide a public login.
